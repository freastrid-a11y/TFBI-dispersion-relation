# `eq73.py` — The TFBI Dispersion Relation

## Overview

This is the core mathematical module of the solver. It implements the kinetic-ion / fluid-electron dispersion relation for the **Thermal Farley-Buneman Instability (TFBI)** — manuscript Eq. (73) — for a weakly ionized, magnetized E-region plasma driven by a background electric field $E_0$ perpendicular to $B_0$.

The dispersion relation is the Poisson condition

$$
\varepsilon(\omega, \mathbf{k}) \;=\; 1 + \chi_e + \chi_i \;=\; 0,
$$

where $\chi_e$ is the **fluid electron susceptibility** and $\chi_i$ is the **kinetic ion susceptibility**. Perturbations are assumed to vary as $\exp(i\mathbf{k}\cdot\mathbf{r} - i\omega t)$, so a root with $\mathrm{Im}(\omega) > 0$ is unstable (growing).

### Physics handled in this module

- **Geometry.** The electron $\mathbf{E}\times\mathbf{B}$ drift $V_d = E_0/B_0$ is along $x$; the background electric field (and therefore the ion Pedersen drift $\mathbf{U}_0$ and the ion acceleration $\mathbf{a}_{i0}$) is along $y$.
- **Magnetization-dependent electron drift.** The electron drift components are reduced by collisions through the electron magnetization parameter $\kappa_e = \Omega_e / \nu_e$:

  $$
  V_{de,x} = \frac{E_0}{B_0}\,\frac{\kappa_e^2}{1+\kappa_e^2},
  \qquad
  V_{de,y} = -\frac{E_0}{B_0}\,\frac{\kappa_e}{1+\kappa_e^2}.
  $$

- **Frictional ion heating and anisotropy.** The Pedersen drift $U_0 = eE_0/(m_i \nu_i)$ heats the ions to an effective temperature $T_\mathrm{eff} = T_n + m_i U_0^2/3$, which is split into anisotropic components $T_x$, $T_y$ via `anisotropy_ratio` (thermal velocities $V_{Tx}$, $V_{Ty}$). This thermal correction is what distinguishes the *thermal* FBI from the classic fluid FBI.
- **Ion acceleration term.** The $i\,\mathbf{k}\cdot\mathbf{a}_{i0}$ term (with $a_{i0} = eE_0/m_i$) enters both kinetic denominators; it can be switched off for comparison runs.
- **Kinetic ions.** The ion response uses the modified plasma dispersion function $\tilde{Z}$ (manuscript Eq. 74, implemented in [`root.Z_tilde`](root.md)) evaluated at two complex arguments $z_1, z_2$ built from the collision-shifted frequency $\omega_i = \omega + i\nu_i$.

### Numerical scaling

The raw susceptibilities are enormous ($\chi \sim 1/(k^2\lambda_D^2)$), which would stall a Newton-type solver. The returned residual is therefore scaled:

$$
\mathrm{eq\_73}(\omega, k_x, k_y) \;=\; k^2 \lambda_D^2\,\bigl(1 + \chi_e + \chi_i\bigr),
$$

bringing all terms down to $\mathcal{O}(1)$ so the root finder in [`root.py`](root.md) converges smoothly. $k^2$ is floored at $10^{-12}$ to avoid division by zero at the origin.

## API Reference

### `eq_73(omega, k_x, k_y, run, a_i0_enabled=True)`

Evaluate the scaled TFBI dispersion residual $k^2\lambda_D^2\,(1 + \chi_e + \chi_i)$.

| Argument | Type | Description |
|---|---|---|
| `omega` | `complex` | Complex wave frequency $\omega = \omega_r + i\gamma$ (rad/s). |
| `k_x` | `float` | Wave number along the electron drift axis (m⁻¹). |
| `k_y` | `float` | Wave number along the electric-field / Pedersen axis (m⁻¹). |
| `run` | `int` | Index into the altitude-dependent arrays in [`constants.py`](constants.md) (`alt_eff`, `nu_i`, `nu_e`, `kappa_e`, …). |
| `a_i0_enabled` | `bool`, optional | If `False`, forces the ion acceleration $\mathbf{a}_{i0}$ to zero. Default `True`. |

**Returns:** `complex` — the scaled dispersion residual. A value of (numerically) zero means $(\omega, \mathbf{k})$ satisfies the dispersion relation.

**Notes**

- Dynamic quantities ($V_{de}$, $U_0$, $T_\mathrm{eff}$, $V_{Tx}$, $V_{Ty}$, $a_{i0}$) are recomputed per call from the selected `run`, so the function is self-consistent for every altitude.
- The electron term uses the isothermal fluid susceptibility
  $\chi_e = \omega_{pe}^2 / \bigl[-i\omega\nu_e(1+\kappa_e^2) + \gamma (T_e/m_e)k^2 + i\nu_e(1+\kappa_e^2)\,\mathbf{k}\cdot\mathbf{V}_{de}\bigr]$.
- The ion term combines $\tilde{Z}(z_1)$ (collision/BGK correction) and $\tilde{Z}(z_2)$ (drifting, anisotropic Maxwellian) via
  $\chi_i \propto \dfrac{1}{1 + \frac{i\nu_i}{\sqrt{2\,\mathrm{den}_1}}\tilde Z(z_1)} \bigl(1 + z_2 \tilde Z(z_2)\bigr)$.

### `eq_73_ai0zero(omega, k_x, k_y, run)`

Convenience wrapper: `eq_73` with `a_i0_enabled=False`. Registered as a separate named equation so that $a_{i0}$-on vs. $a_{i0}$-off runs get **distinct CSV cache files** (see [`grid_cache.py`](grid_cache.md)) and can be differenced with [`csvmethods.plot_field_difference`](csvmethods.md).

| Argument | Type | Description |
|---|---|---|
| `omega`, `k_x`, `k_y`, `run` | — | Same as `eq_73`. |

**Returns:** `complex` — scaled dispersion residual with $\mathbf{a}_{i0} = 0$.

## Usage Examples

Evaluate the residual at a single point:

```python
from eq73 import eq_73

residual = eq_73(omega=100.0 + 5.0j, k_x=30.0, k_y=10.0, run=4)
print(abs(residual))  # ~0 only if (omega, k) is a root
```

Solve for the actual roots at that wave vector:

```python
from eq73 import eq_73
from root import find_roots

roots = find_roots(eq_73, k_x=30.0, k_y=10.0, run=4)
print(roots)  # sorted by decreasing Im(omega); roots[0] is the fastest-growing mode
```

Run a full cached grid + plot from the command line (the module's own `__main__` block does the equivalent of this):

```bash
python main.py --equation eq_73 --method growth_contour --save growth_contour_116km.png --run 3
```

Compare with the acceleration term disabled:

```bash
python main.py --equation eq_73_ai0zero --method growth_contour --save growth_contour_116km_ai0zero.png --run 3
```
